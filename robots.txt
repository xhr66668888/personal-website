# Google/Bing could still list the bare URL when someone links to it.
#
# NOTE: crawlers only read robots.txt at the root of a host
# (e.g. https://example.com/robots.txt). On a GitHub Pages *project* site
# (username.github.io/repo/) this file is ignored; the meta tags do the work.
